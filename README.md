# Day 37 - Logistic Regression

## AI & ML Internship

### Project Overview
Today, I worked on building a Logistic Regression model for a binary classification problem using Python and Scikit-learn.

The project uses the Breast Cancer Dataset to predict whether a tumour is Malignant or Benign.

### Objective
- Understand Logistic Regression.
- Build a binary classification model.
- Split data into training and testing sets.
- Train the model using Scikit-learn.
- Make predictions on test data.
- Evaluate model performance.

### Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

### Dataset
**Breast Cancer Dataset**

The dataset contains numerical features related to breast cancer tumours.

Target classes:
- 0 – Malignant
- 1 – Benign

### Implementation Steps
1. Imported the required Python libraries.
2. Loaded the Breast Cancer Dataset.
3. Converted the dataset into a Pandas DataFrame.
4. Checked the dataset and missing values.
5. Separated features and target variables.
6. Split the dataset into training and testing data.
7. Applied StandardScaler for feature scaling.
8. Created and trained the Logistic Regression model.
9. Predicted results using test data.
10. Evaluated the model using accuracy score, confusion matrix and classification report.

### Model Evaluation
The model was evaluated using:

- Accuracy Score
- Confusion Matrix
- Precision
- Recall
- F1-Score

### Key Learnings
- Learned the basics of Logistic Regression.
- Understood binary classification.
- Practiced training and testing machine learning models.
- Learned feature scaling using StandardScaler.
- Understood how machine learning models make predictions.
- Learned basic model evaluation techniques.

### Conclusion
Successfully implemented a Logistic Regression model using Scikit-learn.

This task helped me understand the basics of classification and how machine learning algorithms can be used to make predictions from numerical data.
